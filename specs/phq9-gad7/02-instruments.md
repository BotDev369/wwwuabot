## 4. PHQ-9: питання, відповіді, підрахунок

### 4.1. Варіанти відповідей (однакові для всіх 9 питань)

| Текст | Бали |
|---|---|
| Зовсім ні | 0 |
| Кілька днів | 1 |
| Більше половини днів | 2 |
| Майже щодня | 3 |

### 4.2. Питання

| № | Текст питання | Кластер (для інтерпретації) |
|---|---|---|
| 1 | Малий інтерес або відсутність задоволення від того, що ви робите | Ядро настрою |
| 2 | Поганий настрій, пригніченість або відчуття безнадійності | Ядро настрою |
| 3 | Проблеми зі сном: важко заснути, часто прокидаєтеся вночі або, навпаки, спите надто багато | Соматичний |
| 4 | Втома або відчуття браку енергії | Соматичний |
| 5 | Поганий апетит або переїдання | Соматичний |
| 6 | Погане ставлення до себе: відчуття, що ви невдаха або підвели себе чи свою родину | Когнітивно-афективний |
| 7 | Труднощі з концентрацією уваги, наприклад, під час читання чи перегляду телевізора | Когнітивно-афективний |
| 8 | Настільки повільні рухи або мовлення, що інші могли це помітити. Або навпаки, настільки виражений неспокій, що ви рухалися значно більше, ніж зазвичай | Соматичний (психомоторний) |
| 9 | Думки про те, що вам краще було б померти, або про те, щоб якимось чином завдати собі шкоди | **Критичний (безпека)** |

### 4.3. Додаткове запитання про вплив на життя (не входить у суму балів)

**Текст:** Якщо ви позначили будь-яку з проблем вище, наскільки вони ускладнили вам роботу, ведення домашніх справ або спілкування з іншими людьми?

| Відповідь | Код |
|---|---|
| Зовсім не ускладнили | 0 |
| Певною мірою ускладнили | 1 |
| Дуже ускладнили | 2 |
| Надзвичайно ускладнили | 3 |

Це запитання показувати **лише якщо** хоча б одна з відповідей 1–9 відмінна від «Зовсім ні». Інакше пропустити його та записати як `null`.

## 6. Логіка підрахунку

```
PHQ9_total = сума відповідей питань 1–9          // 0..27
GAD7_total = сума відповідей питань 1–7          // 0..21
PHQ9_item9 = відповідь на питання 9              // 0..3
PHQ9_impact, GAD7_impact = 0..3 або null         // не входять у суму
```

### 6.1. Рівні вираженості PHQ-9

| Сума | Ключ | Назва рівня | Колір |
|---|---|---|---|
| 0–4 | `phq_minimal` | Мінімальні або відсутні симптоми депресії | зелений |
| 5–9 | `phq_mild` | Легкі симптоми | світло-жовтий |
| 10–14 | `phq_moderate` | Помірні симптоми | жовто-помаранчевий |
| 15–19 | `phq_modsevere` | Помірно виражені (значні) симптоми | помаранчевий |
| 20–27 | `phq_severe` | Тяжкі симптоми | червоний |

Сума **≥ 10** — стандартна межа, з якої рекомендується додаткова оцінка фахівцем (чутливість і специфічність для великого депресивного епізоду близько 88%).

### 6.2. Рівні вираженості GAD-7

| Сума | Ключ | Назва рівня | Колір |
|---|---|---|---|
| 0–4 | `gad_minimal` | Мінімальна тривога | зелений |
| 5–9 | `gad_mild` | Легка тривога | світло-жовтий |
| 10–14 | `gad_moderate` | Помірна тривога | помаранчевий |
| 15–21 | `gad_severe` | Виражена (тяжка) тривога | червоний |

Сума **≥ 10** — стандартна межа для генералізованого тривожного розладу (чутливість близько 89%, специфічність близько 82%). Деякі дослідження рекомендують межу **≥ 8** для скринінгу: вона виявляє більше випадків, але дає більше хибнопозитивних результатів. У віджеті використовувати межу 10 для рекомендацій, а діапазон 8–9 позначати як «на межі».

### 6.3. Прапорці для логіки відображення

```
flag_suicide_risk  = PHQ9_item9 >= 1                 // будь-яка відповідь > 0
flag_phq_positive  = PHQ9_total >= 10
flag_gad_positive  = GAD7_total >= 10
flag_comorbid      = flag_phq_positive && flag_gad_positive
flag_core_mood     = (item1 >= 2) || (item2 >= 2)    // ядро настрою на рівні "більше половини днів" і вище
flag_impact_high   = impact >= 2                     // "дуже" або "надзвичайно" ускладнили
```

### 6.4. Тригерні тексти за окремими питаннями

Для кожного питання зі відповіддю **≥ 2** («Більше половини днів» або «Майже щодня») додатково показувати відповідний короткий блок з розділу 7.6 (для PHQ-9) або 7.7 (для GAD-7). Це робить інтерпретацію персональною.
