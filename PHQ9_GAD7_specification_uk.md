# Специфікація для AI-агента: онлайн-скринінг депресії та тривоги (PHQ-9 + GAD-7), українська мова

> **Призначення документа.** Це повне технічне та змістове завдання для реалізації закритого веб-віджета скринінгу. Тут є все: тексти інтерфейсу, питання, варіанти відповідей, логіка підрахунку, правила безпеки, повна інтерпретація результатів. Агент має реалізувати віджет, **не змінюючи формулювань питань і варіантів відповідей**.

## 0. Ключові правила для агента (прочитати першими)

1. Питання і варіанти відповідей (розділи 4 і 5) вставляти **дослівно**, нічого не переформульовувати, не скорочувати й не «покращувати».
2. Підрахунок робити строго за розділом 6. Бали: 0, 1, 2, 3.
3. Результат завжди подавати як **скринінг, а не діагноз**. Обов'язкова примітка з розділу 3.4 має бути на екрані результату.
4. **Питання 9 PHQ-9 — критичне.** Будь-яка відповідь, відмінна від «Зовсім ні», запускає протокол безпеки (розділ 8) **незалежно від загальної суми**.
5. Тексти інтерпретації (розділ 7) не скорочувати. Вони мають показуватися у структурованому вигляді (згортні блоки допустимі, але весь зміст має бути доступний).
6. Персональні дані не збирати без потреби (розділ 9).
7. Довідкові номери телефонів у розділі 8 вставляти як є, у вигляді клікабельних `tel:` посилань.

## 3. Загальний сценарій і тексти інтерфейсу

### 3.1. Порядок екранів

1. **Вітальний екран** — тексти з 3.2, кнопка «Почати».
2. **Блок PHQ-9** — 9 питань (по одному на екран, з прогрес-баром), потім запитання про вплив на життя.
3. **Блок GAD-7** — 7 питань, потім запитання про вплив на життя.
4. **Екран результатів** — див. розділи 6–8.

Питання по одному на екран, з кнопкою «Назад» і показом прогресу («Питання 3 з 9»). Кнопка «Далі» неактивна, поки не обрано відповідь. Можна дозволити перехід автоматично після вибору.

Порядок блоків: якщо потрібно, можна поставити GAD-7 першим. Логіка від порядку не залежить.

### 3.2. Вітальний екран

**Заголовок:** Скринінг настрою та тривоги

**Текст:**
> Цей тест допоможе оцінити, як ви почувалися протягом останніх двох тижнів. Він складається з двох коротких частин: перша стосується настрою, друга — тривоги. Це займе приблизно 3–5 хвилин.
>
> Відповідайте так, як було насправді, а не так, як «мало б бути». Правильних чи неправильних відповідей немає. Обирайте те, що найточніше описує ваш стан.
>
> Ваші відповіді [не зберігаються / зберігаються лише за вашою згодою] (обрати відповідно до налаштувань проєкту).
>
> **Важливо:** цей тест — інструмент самооцінки, а не медичний діагноз. Він не замінює консультацію лікаря або психолога.

**Кнопка:** Почати

### 3.3. Інструкція перед кожним блоком

- Перед PHQ-9 та GAD-7 показувати однакову інструкцію (вона ж — заголовок кожного питання):

> **Протягом останніх 2 тижнів як часто вас турбували наведені нижче проблеми?**

### 3.4. Обов'язкова примітка на екрані результатів (не забирати, не приховувати)

> **Це скринінговий інструмент, а не діагноз.** Результат показує, наскільки вираженими були ваші симптоми за останні два тижні, і не може встановити причину. Діагноз ставить лише кваліфікований фахівець на основі бесіди та обстеження. Якщо результати вас непокоять або ви почуваєтеся гірше, зверніться до лікаря чи психолога. Ви заслуговуєте на підтримку, і звернення по допомогу — це ознака турботи про себе.

## 4. PHQ-9: питання, відповіді, підрахунок

### 4.1. Варіанти відповідей (однакові для всіх 9 питань)

| Текст | Бали |
|---|---|
| Зовсім ні | 0 |
| Кілька днів | 1 |
| Більше половини днів | 2 |
| Майже щодня | 3 |

### 4.2. Питання

| № | Текст питання | Кластер (для інтерпретації) |
|---|---|---|
| 1 | Малий інтерес або відсутність задоволення від того, що ви робите | Ядро настрою |
| 2 | Поганий настрій, пригніченість або відчуття безнадійності | Ядро настрою |
| 3 | Проблеми зі сном: важко заснути, часто прокидаєтеся вночі або, навпаки, спите надто багато | Соматичний |
| 4 | Втома або відчуття браку енергії | Соматичний |
| 5 | Поганий апетит або переїдання | Соматичний |
| 6 | Погане ставлення до себе: відчуття, що ви невдаха або підвели себе чи свою родину | Когнітивно-афективний |
| 7 | Труднощі з концентрацією уваги, наприклад, під час читання чи перегляду телевізора | Когнітивно-афективний |
| 8 | Настільки повільні рухи або мовлення, що інші могли це помітити. Або навпаки, настільки виражений неспокій, що ви рухалися значно більше, ніж зазвичай | Соматичний (психомоторний) |
| 9 | Думки про те, що вам краще було б померти, або про те, щоб якимось чином завдати собі шкоди | **Критичний (безпека)** |

### 4.3. Додаткове запитання про вплив на життя (не входить у суму балів)

**Текст:** Якщо ви позначили будь-яку з проблем вище, наскільки вони ускладнили вам роботу, ведення домашніх справ або спілкування з іншими людьми?

| Відповідь | Код |
|---|---|
| Зовсім не ускладнили | 0 |
| Певною мірою ускладнили | 1 |
| Дуже ускладнили | 2 |
| Надзвичайно ускладнили | 3 |

Це запитання показувати **лише якщо** хоча б одна з відповідей 1–9 відмінна від «Зовсім ні». Інакше пропустити його та записати як `null`.

## 6. Логіка підрахунку

```
PHQ9_total = сума відповідей питань 1–9          // 0..27
GAD7_total = сума відповідей питань 1–7          // 0..21
PHQ9_item9 = відповідь на питання 9              // 0..3
PHQ9_impact, GAD7_impact = 0..3 або null         // не входять у суму
```

### 6.1. Рівні вираженості PHQ-9

| Сума | Ключ | Назва рівня | Колір |
|---|---|---|---|
| 0–4 | `phq_minimal` | Мінімальні або відсутні симптоми депресії | зелений |
| 5–9 | `phq_mild` | Легкі симптоми | світло-жовтий |
| 10–14 | `phq_moderate` | Помірні симптоми | жовто-помаранчевий |
| 15–19 | `phq_modsevere` | Помірно виражені (значні) симптоми | помаранчевий |
| 20–27 | `phq_severe` | Тяжкі симптоми | червоний |

Сума **≥ 10** — стандартна межа, з якої рекомендується додаткова оцінка фахівцем (чутливість і специфічність для великого депресивного епізоду близько 88%).

### 6.2. Рівні вираженості GAD-7

| Сума | Ключ | Назва рівня | Колір |
|---|---|---|---|
| 0–4 | `gad_minimal` | Мінімальна тривога | зелений |
| 5–9 | `gad_mild` | Легка тривога | світло-жовтий |
| 10–14 | `gad_moderate` | Помірна тривога | помаранчевий |
| 15–21 | `gad_severe` | Виражена (тяжка) тривога | червоний |

Сума **≥ 10** — стандартна межа для генералізованого тривожного розладу (чутливість близько 89%, специфічність близько 82%). Деякі дослідження рекомендують межу **≥ 8** для скринінгу: вона виявляє більше випадків, але дає більше хибнопозитивних результатів. У віджеті використовувати межу 10 для рекомендацій, а діапазон 8–9 позначати як «на межі».

### 6.3. Прапорці для логіки відображення

```
flag_suicide_risk  = PHQ9_item9 >= 1                 // будь-яка відповідь > 0
flag_phq_positive  = PHQ9_total >= 10
flag_gad_positive  = GAD7_total >= 10
flag_comorbid      = flag_phq_positive && flag_gad_positive
flag_core_mood     = (item1 >= 2) || (item2 >= 2)    // ядро настрою на рівні "більше половини днів" і вище
flag_impact_high   = impact >= 2                     // "дуже" або "надзвичайно" ускладнили
```

### 6.4. Тригерні тексти за окремими питаннями

Для кожного питання зі відповіддю **≥ 2** («Більше половини днів» або «Майже щодня») додатково показувати відповідний короткий блок з розділу 7.6 (для PHQ-9) або 7.7 (для GAD-7). Це робить інтерпретацію персональною.

## 7. Тексти інтерпретації (показувати користувачеві)

Структура екрана результатів:

1. Заголовок і загальний підсумок (7.1)
2. Результат PHQ-9: бали, рівень, розгорнутий опис (7.2)
3. Результат GAD-7: бали, рівень, розгорнутий опис (7.3)
4. Вплив на повсякденне життя (7.4)
5. Комбінований висновок за двома шкалами (7.5)
6. Персональні акценти за окремими питаннями (7.6–7.7)
7. Що робити далі: самодопомога, коли звертатися, як відстежувати динаміку (7.8–7.10)
8. Обмеження тесту (7.11)
9. Обов'язкова примітка (3.4), авторство (розділ 2), контакти допомоги (розділ 8)

### 7.1. Загальний підсумок (шаблон)

> **Ваш результат**
>
> Депресивні симптоми (PHQ-9): **{PHQ9_total} з 27** — {назва рівня}.
> Тривожні симптоми (GAD-7): **{GAD7_total} з 21** — {назва рівня}.
>
> Ці цифри описують, як ви почувалися останні два тижні. Вони не є діагнозом, але допомагають зрозуміти, чи варто звернути на свій стан більше уваги.

### 7.2. Інтерпретація PHQ-9 за рівнями

#### `phq_minimal` (0–4)

> **Мінімальні симптоми депресії**
>
> За останні два тижні у вас практично не було ознак, які вкладаються в картину депресії. Ви, найімовірніше, зберігаєте інтерес до життя, відчуваєте достатньо енергії й загалом справляєтеся з повсякденними завданнями.
>
> **Що це означає.** Іноді трапляються погані дні, і це нормально. Настрій природно коливається залежно від подій, сну, навантаження та самопочуття. Такий результат не означає, що у вас усе «ідеально», він означає, що вираженого зниження настрою зараз не помітно.
>
> **Що робити.** Підтримуйте те, що допомагає: регулярний сон, рух, спілкування з близькими, справи, які приносять задоволення. Тест можна пройти знову, якщо ви помітите, що настрій погіршується, або після тривалого стресу, втрати чи великих змін у житті.

#### `phq_mild` (5–9)

> **Легкі симптоми депресії**
>
> За останні два тижні ви помічали окремі ознаки зниженого настрою, втоми або втрати інтересу. Вони не обов'язково постійні й, можливо, не сильно заважають життю, але вони є.
>
> **Що це означає.** Такий рівень трапляється часто, зокрема в періоди стресу, перевантаження, нестачі сну, після втрат, у складних життєвих обставинах. Це ще не означає депресивного розладу, але сигнал прислухатися до себе, а не «терпіти».
>
> **Що робити.**
> - Поспостерігайте за станом протягом наступних 2 тижнів і пройдіть тест повторно.
> - Приділіть увагу базовим речам: режим сну, регулярне харчування, щоденна фізична активність (навіть 20–30 хвилин прогулянки), світло й свіже повітря, обмеження алкоголю.
> - Не відмовляйтеся від справ, що раніше приносили задоволення, навіть коли «не хочеться»: інколи задоволення приходить після дії, а не перед нею.
> - Поговоріть з кимось із близьких про свій стан. Самотність підсилює пригніченість.
> - Якщо протягом двох тижнів стан не покращується або погіршується, зверніться до сімейного лікаря чи психолога.

#### `phq_moderate` (10–14)

> **Помірні симптоми депресії**
>
> За останні два тижні симптоми були достатньо помітними: зниження настрою, втрата інтересу, втома, труднощі зі сном чи концентрацією. Такий результат перебуває вище стандартної межі, за якої фахівці рекомендують додаткову оцінку.
>
> **Що це означає.** Це не діагноз, але й не «просто поганий настрій». Такі симптоми зазвичай помітно впливають на самопочуття й можуть ускладнювати роботу та стосунки. Депресія такого рівня добре піддається лікуванню, і чим раніше звернутися, тим легше відновлення.
>
> **Що робити.**
> - **Рекомендується звернутися до лікаря або психолога/психотерапевта** для оцінювання стану. Почати можна із сімейного лікаря: він допоможе виключити фізичні причини (наприклад, порушення щитоподібної залози, анемію, дефіцит вітаміну D чи В12, побічну дію ліків).
> - Ефективні підходи при такому рівні включають психотерапію (зокрема когнітивно-поведінкову), а в деяких випадках — медикаментозне лікування за призначенням лікаря. Лише спеціаліст може визначити, що вам підходить.
> - Уже зараз допоможе «поведінкова активація»: щодня плануйте 1–2 маленькі справи (прогулянка, душ, дзвінок другу, приготування їжі) і виконуйте їх незалежно від настрою.
> - Спробуйте не залишатися наодинці зі станом: розкажіть комусь довіреному.
> - Пройдіть тест знову через 2 тижні, щоб побачити динаміку.

#### `phq_modsevere` (15–19)

> **Помірно виражені (значні) симптоми депресії**
>
> За останні два тижні симптоми були вираженими й, імовірно, суттєво впливали на ваше життя: настрій, енергію, сон, апетит, самооцінку, здатність зосередитися й отримувати задоволення.
>
> **Що це означає.** Такий рівень найчастіше відповідає стану, який потребує активного лікування, а не лише самодопомоги. Це не «слабкість» і не «лінь»: депресія — це стан, що має біологічні, психологічні та соціальні чинники, і він піддається лікуванню.
>
> **Що робити.**
> - **Варто найближчим часом звернутися до лікаря-психіатра, психотерапевта або клінічного психолога.** Не відкладайте: чим раніше почати лікування, тим швидше зазвичай настає покращення.
> - Лікування може поєднувати психотерапію та (за показаннями) медикаментозну терапію. Рішення приймає лікар разом із вами.
> - Тим часом дбайте про мінімум: їжа, вода, сон, коротка прогулянка. Не змушуйте себе робити багато, обирайте найпростіше.
> - Повідомте близьку людину про свій стан і попросіть підтримки, зокрема допомогти домовитися про прийом.
> - Уникайте алкоголю та інших речовин: вони погіршують настрій і сон.
> - Якщо з'являються думки про самоушкодження чи небажання жити, негайно зверніться по допомогу (див. контакти внизу).

#### `phq_severe` (20–27)

> **Тяжкі симптоми депресії**
>
> За останні два тижні симптоми були дуже вираженими. Ймовірно, вони значно впливають на повсякденне життя, роботу, стосунки й самопочуття.
>
> **Що це означає.** Такий рівень вказує на те, що потрібна професійна допомога. Це не вирок і не ваша вина. Депресія такої вираженості є серйозним, але лікованим станом. Багато людей з таким результатом відновлюються після відповідного лікування.
>
> **Що робити.**
> - **Будь ласка, зверніться до лікаря-психіатра або психотерапевта якнайшвидше, бажано впродовж кількох днів.** Якщо не знаєте, з чого почати, зателефонуйте сімейному лікарю або на гарячу лінію (контакти внизу).
> - Скажіть близькій людині про свій стан, попросіть бути поруч і допомогти з організацією візиту до лікаря. Не залишайтеся наодинці.
> - Не приймайте великих життєвих рішень у цей період. Стан може спотворювати сприйняття, і багато що виглядає безнадійнішим, ніж є насправді.
> - Не вживайте алкоголь і не «лікуйте» стан самостійно препаратами.
> - Якщо вам здається, що ви не можете безпечно дочекатися прийому, або з'явилися думки про самоушкодження, **телефонуйте на кризові лінії або за номером 112 негайно** (розділ 8).

### 7.3. Інтерпретація GAD-7 за рівнями

#### `gad_minimal` (0–4)

> **Мінімальна тривога**
>
> Протягом останніх двох тижнів вираженої тривоги у вас не було. Вам, імовірно, переважно вдається розслаблятися і не піддаватися надмірному занепокоєнню.
>
> **Що це означає.** Певна тривога — нормальна реакція, яка допомагає передбачати небезпеку та готуватися до складних ситуацій. Ваш рівень не виходить за межі того, що трапляється в більшості людей.
>
> **Що робити.** Продовжуйте практики, що допомагають розслабленню та відновленню. Якщо в майбутньому тривога посилиться, пройдіть тест знову.

#### `gad_mild` (5–9)

> **Легка тривога**
>
> Ви помічали деякі прояви тривоги: напругу, занепокоєння, труднощі з розслабленням. Вони, ймовірно, не є постійними й не заважають життю кардинально.
>
> **Що це означає.** Легка тривога поширена, особливо в періоди невизначеності, підвищеного навантаження або складних подій. Вона може минути самостійно, коли ситуація стабілізується, але й може посилюватися, якщо стрес затягується.
>
> **Що робити.**
> - Спробуйте практики, які знижують рівень збудження: повільне дихання (вдих на 4 секунди, видих на 6–8, кілька хвилин), прогресивна м'язова релаксація, прогулянка.
> - Обмежте кофеїн, особливо після обіду, і подивіться на вплив новинного споживання: постійне «гортання» новин підсилює тривогу.
> - Виділяйте час для «відкладеного хвилювання»: 15 хвилин на день, коли ви записуєте тривожні думки, а поза цим часом повертаєтеся до справ.
> - Підтримуйте фізичну активність і регулярний сон.
> - Повторіть тест через 2 тижні. Якщо результат зростає, зверніться до лікаря чи психолога.

#### `gad_moderate` (10–14)

> **Помірна тривога**
>
> Протягом останніх двох тижнів тривога була вираженою: вам було складно розслабитися, контролювати занепокоєння, ви могли відчувати напругу, дратівливість або передчуття лиха. Цей результат перебуває на межі або вище стандартної межі, з якої рекомендують додаткову оцінку.
>
> **Що це означає.** Такий рівень може відповідати тривожному розладу, але остаточно це може визначити лише фахівець. Тривога помірної вираженості зазвичай помітно впливає на сон, концентрацію, стосунки та працездатність. Вона добре піддається лікуванню.
>
> **Що робити.**
> - **Рекомендується консультація лікаря або психолога/психотерапевта.** Лікар також може перевірити фізичні причини тривоги (наприклад, надмірну функцію щитоподібної залози, вплив кофеїну, ліків чи інших речовин).
> - Найкраще вивчена психотерапія при тривозі — когнітивно-поведінкова терапія. У деяких випадках лікар може запропонувати медикаментозне лікування. Рішення завжди індивідуальне.
> - Уже зараз корисні техніки заземлення (наприклад: назвіть 5 речей, які бачите, 4, яких можете торкнутися, 3, які чуєте, 2, які відчуваєте на запах, 1, яку можете скуштувати) і регулярне дихання з довгим видихом.
> - Не уникайте того, що викликає тривогу: уникання її закріплює. Рухайтеся маленькими кроками.
> - Пройдіть тест повторно через 2 тижні.

#### `gad_severe` (15–21)

> **Виражена (тяжка) тривога**
>
> Тривога за останні два тижні була дуже вираженою. Ймовірно, вона значно впливає на сон, здатність зосереджуватись, стосунки, роботу й загальне самопочуття.
>
> **Що це означає.** Цей результат вказує на те, що потрібна професійна оцінка стану. Тривога такої вираженості виснажує, але вона лікується, а більшість людей отримують значне полегшення після відповідної допомоги.
>
> **Що робити.**
> - **Зверніться до лікаря-психіатра, психотерапевта або клінічного психолога найближчим часом.** Якщо не знаєте, з чого почати, почніть із сімейного лікаря або гарячої лінії (розділ 8).
> - Якщо ви відчуваєте напади сильного страху з серцебиттям, задишкою, запамороченням чи відчуттям нереальності (панічні атаки), скажіть про це лікареві: це допоможе підібрати лікування.
> - Тимчасово допомагають повільне дихання, заземлення, зниження кофеїну й алкоголю (вони підсилюють тривогу), розмова з близькою людиною.
> - Якщо симптоми є нестерпними або супроводжуються думками про самоушкодження, негайно зверніться по допомогу (розділ 8).

### 7.4. Вплив на повсякденне життя (показувати за відповіддю на додаткове запитання)

Показувати окремо для PHQ-9 та GAD-7, з відповідною назвою («Настрій» / «Тривога»).

| Код | Текст |
|---|---|
| 0 (або запитання не показувалось) | Ви зазначили, що ці проблеми не ускладнюють вам повсякденне життя. Це хороша ознака: навіть якщо симптоми є, ви зберігаєте здатність справлятися з роботою, домашніми справами та спілкуванням. |
| 1 | Ви зазначили, що ці проблеми **певною мірою** ускладнюють вам життя. Це означає, що вони вже відчутні в повсякденні. Варто звернути на них увагу, поки вони не посилилися, і, за потреби, порадитися з фахівцем. |
| 2 | Ви зазначили, що ці проблеми **дуже** ускладнюють вам життя. Коли симптоми помітно заважають роботі, дому чи стосункам, це серйозний привід звернутися по професійну допомогу, незалежно від суми балів. |
| 3 | Ви зазначили, що ці проблеми **надзвичайно** ускладнюють вам життя. Це означає, що ваш стан суттєво обмежує вас. Будь ласка, зверніться по допомогу до лікаря чи психолога найближчим часом. Ви не мусите справлятися самостійно. |

> Логіка: якщо `impact >= 2`, а сума балів у межах «легко/мінімально», додати пояснення: *«Навіть при невисокій сумі балів те, що симптоми сильно заважають вам жити, є достатньою підставою для консультації фахівця.»*

### 7.5. Комбінований висновок за двома шкалами

Показувати **один** блок залежно від комбінації. Порядок перевірки: зверху вниз, перша відповідність.

**A. Обидва результати ≥ 10 (`flag_comorbid`):**

> **Поєднання депресивних і тривожних симптомів**
>
> У вас виражені і симптоми зниженого настрою, і симптоми тривоги. Таке поєднання дуже поширене: тривога й депресія часто йдуть поруч і підсилюють одне одного. Ви можете відчувати виснаження й одночасно внутрішню напругу, що затьмарює здатність відпочивати.
>
> Це важливий привід звернутися до фахівця: при поєднанні симптомів лікування підбирається з урахуванням обох станів. Багатьом людям допомагає психотерапія (когнітивно-поведінковий підхід), а за показаннями — медикаментозне лікування. Спробуйте не відкладати консультацію.

**B. PHQ-9 ≥ 10, GAD-7 < 10:**

> **Переважають симптоми зниженого настрою**
>
> Основне навантаження припадає на настрій, інтерес до життя й енергію, тоді як виражена тривога відсутня. Найважливіше зараз — звернутися по оцінку стану й підтримку та подбати про мінімальні потреби: сон, харчування, короткі прогулянки.

**C. GAD-7 ≥ 10, PHQ-9 < 10:**

> **Переважають симптоми тривоги**
>
> Основне навантаження припадає на тривогу, напругу та занепокоєння, тоді як виражених ознак депресії немає. Корисно навчитися технікам регуляції збудження та за потреби отримати консультацію фахівця. Тривога, яка триває, може з часом виснажувати й підвищувати ризик зниження настрою, тому не варто чекати, поки стане нестерпно.

**D. Обидва результати в діапазоні 5–9:**

> **Легкі прояви обох станів**
>
> Ви помічаєте як деяке зниження настрою, так і тривогу, але вони не досягають рівня, що зазвичай потребує лікування. Це хороший момент для профілактики: подбайте про сон, рух, підтримку близьких, зменшіть навантаження, де це можливо. Повторіть тест через 2 тижні.

**E. Обидва результати < 5:**

> **Ознаки вираженого дистресу відсутні**
>
> За обома шкалами ваші результати перебувають у межах, що не викликають занепокоєння. Це не означає, що вам не буває важко, але зараз ви справляєтеся. Продовжуйте дбати про себе й пройдіть тест знову, якщо щось зміниться.

**F. Решта комбінацій (наприклад, один результат 5–9, інший < 5):**

> Ваші результати перебувають на межі легких проявів. Прислухайтеся до себе, подбайте про відпочинок і підтримку й пройдіть тест повторно через 2 тижні.

### 7.6. Персональні акценти за питаннями PHQ-9 (показувати, якщо відповідь ≥ 2)

Показувати у вигляді розділу «На що варто звернути увагу» з коротким переліком.

| Питання | Текст |
|---|---|
| 1 (інтерес) | **Втрата інтересу й задоволення.** Ви відзначили, що більшість днів мало що цікавить або тішить. Це один із двох ключових симптомів депресії. Спробуйте щодня планувати одну маленьку приємну або значущу справу й виконувати її, навіть якщо не хочеться, а потім помітити свої відчуття. |
| 2 (настрій) | **Пригнічений настрій або безнадійність.** Це один із двох ключових симптомів депресії. Відчуття безнадійності часто є частиною самого стану і не відображає реальних перспектив. Розкажіть про це близькій людині або фахівцеві. |
| 3 (сон) | **Порушення сну.** Сон і настрій тісно пов'язані. Допомагають однакові час засинання й підйому, відсутність екранів за годину до сну, обмеження кофеїну, прохолодна темна кімната. Якщо порушення тривають понад 2–3 тижні, скажіть лікареві: існують ефективні методи (зокрема когнітивно-поведінкова терапія безсоння). |
| 4 (втома) | **Втома й брак енергії.** Це може бути ознакою депресії, але також анемії, проблем зі щитоподібною залозою, нестачі сну чи інших станів. Варто пройти базове медичне обстеження. |
| 5 (апетит) | **Зміни апетиту.** Втрата апетиту або переїдання — поширений прояв стресу й пригніченого настрою. Спробуйте їсти регулярно, навіть невеликими порціями. Якщо зміни супроводжуються помітною зміною ваги, зверніться до лікаря. |
| 6 (самооцінка) | **Самокритика й почуття провини.** Депресія «забарвлює» думки в негативні тони, і те, що вважаєте фактом про себе, часто є симптомом. Спробуйте уявити, що сказали б другу в такій ситуації. Терапевтичні підходи, зокрема когнітивно-поведінкова терапія, допомагають працювати з такими думками. |
| 7 (концентрація) | **Труднощі з концентрацією.** Це поширений прояв як депресії, так і тривоги та недосипання. Розбивайте завдання на малі кроки, робіть паузи, зменшіть кількість відволікаючих чинників. Не сприймайте це як «слабкий розум»: це симптом, який зазвичай зменшується при покращенні стану. |
| 8 (психомоторні зміни) | **Зміни в темпі рухів або мовлення.** Помітне сповільнення чи, навпаки, підвищена метушливість — ознаки, які інколи помічають оточуючі. Про це варто окремо розповісти лікареві. |
| 9 | Див. розділ 8, це питання обробляється окремо. |

### 7.7. Персональні акценти за питаннями GAD-7 (показувати, якщо відповідь ≥ 2)

| Питання | Текст |

### 7.8. Загальні поради із самодопомоги (показувати як розділ «Що можна робити вже сьогодні», незалежно від рівня, але з акцентом залежно від результатів)

1. **Сон.** Однаковий час засинання й підйому, 7–9 годин сну, без екранів за годину до сну, прохолодна темна кімната.
2. **Рух.** 20–30 хвилин прогулянки щодня. Фізична активність — один з найкраще вивчених способів покращити настрій і знизити тривогу.
3. **Режим харчування.** Регулярна їжа, достатньо води, менше кофеїну й цукру, мінімум алкоголю.
4. **Соціальні контакти.** Навіть коротка розмова чи повідомлення знайомій людині допомагає. Не чекайте, поки «захочеться».
5. **Поведінкова активація.** Щодня 1–2 маленькі заплановані справи, що дають відчуття значущості або задоволення.
6. **Регуляція збудження.** Дихання «4–6» (вдих 4 с, видих 6–8 с, 3–5 хвилин), заземлення «5-4-3-2-1», прогресивна м'язова релаксація.
7. **Інформаційна гігієна.** Обмежте час із новинами й соцмережами, особливо перед сном.
8. **Робота з думками.** Записуйте тривожні або самокритичні думки й запитуйте себе: «Які є докази за й проти? Що б я сказав другу?»
9. **Не залишайтеся наодинці зі станом.** Розмова з близькою людиною або фахівцем зменшує навантаження.

> Не подавати ці поради як заміну лікування при рівнях `moderate` і вище.

### 7.9. Коли обов'язково звернутися до фахівця

> - ви вживаєте алкоголь чи інші речовини, щоб полегшити стан;
> - виникають думки про те, що краще було б померти, або про самоушкодження. У цьому випадку **не чекайте**, а зверніться по допомогу негайно (розділ 8).

### 7.10. Як відстежувати динаміку

> **Повторне проходження тесту.** Рекомендовано проходити тест повторно **кожні 2 тижні**, оскільки він оцінює останні два тижні. Якщо ви проходите лікування, порівнюйте результати між візитами.
>
> **Що вважається значущою зміною.** Зменшення суми PHQ-9 приблизно на 5 балів і більше або GAD-7 приблизно на 4 бали й більше зазвичай розцінюють як клінічно значуще покращення. Збільшення на цю ж величину — сигнал погіршення, про який варто повідомити фахівця. Ці орієнтири наближені, оцінювати динаміку краще разом із лікарем.

### 7.11. Обмеження тестів (показувати обов'язково, у розгорнутому блоці «Про обмеження»)

> **Що цей тест може й чого не може.**
>
> - Тест **не встановлює діагноз**. Він вимірює вираженість симптомів за останні 2 тижні.
> - Він **не розрізняє причини**. Схожі симптоми можуть бути наслідком фізичних захворювань (щитоподібна залоза, анемія, порушення сну, хронічні захворювання), прийому ліків або речовин, а також природної реакції на горе, втрату чи травматичну подію.
> - PHQ-9 **не відрізняє** звичайну депресію від депресивної фази біполярного розладу. Якщо у вас або ваших рідних були епізоди підвищеного настрою, надмірної енергії й зменшеної потреби у сні, обов'язково скажіть про це лікареві.
> - GAD-7 найкраще виявляє генералізовану тривогу. Він **гірше виявляє** панічний розлад, соціальну тривогу та посттравматичний стресовий розлад (ПТСР). Низький результат не виключає ці стани. Якщо ви пережили травматичну подію (зокрема воєнні дії, втрату, насильство) й маєте нав'язливі спогади, кошмари, уникання чи постійну настороженість, зверніться до фахівця незалежно від результатів тесту.
> - У періоди війни, втрати чи інших екстремальних подій багато проявів (тривога, порушення сну, зниження настрою) є **нормальною реакцією на ненормальні обставини**. Однак якщо вони тривають, посилюються й заважають життю, це привід для допомоги.

> - Відповіді залежать від вашої чесності та самооцінки. Тест не замінює бесіду з фахівцем.

## 11. Псевдокод

```js
function score(answers) {
  const phq = answers.phq.reduce((a, b) => a + b, 0);       // 9 значень
  const gad = answers.gad.reduce((a, b) => a + b, 0);       // 7 значень
  const item9 = answers.phq[8];

  return {
    phq, gad,
    phqBand: bandOf(phq, PHQ_BANDS),
    gadBand: bandOf(gad, GAD_BANDS),
    flags: {
      suicideRisk: item9 >= 1,
      phqPositive: phq >= 10,
      gadPositive: gad >= 10,
      comorbid: phq >= 10 && gad >= 10,
      coreMood: answers.phq[0] >= 2 || answers.phq[1] >= 2,
      impactHigh: (answers.phqImpact ?? 0) >= 2 || (answers.gadImpact ?? 0) >= 2
    },
    phqHighlights: answers.phq.map((v, i) => v >= 2 ? i + 1 : null).filter(Boolean),
    gadHighlights: answers.gad.map((v, i) => v >= 2 ? i + 1 : null).filter(Boolean)
  };
}
```

Порядок виведення результатів: блок безпеки (якщо `suicideRisk`) → підсумок → PHQ-9 → GAD-7 → вплив на життя → комбінований висновок → акценти → самодопомога → коли звертатися → динаміка → обмеження → примітка й контакти.
