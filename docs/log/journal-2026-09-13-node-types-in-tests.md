### 13.09.2026 — `@types/node` у `packages/shared`: транзитивний тип — не контракт

**Симптом:** PR Dependabot «vitest 3.2.7 → 5.0.0» падав єдиним кроком `typecheck`, у
`packages/shared`:

```
src/config/wrangler-env.test.ts(23,55): error TS2591: Cannot find name 'node:fs'.
  Do you need to install type definitions for node? Try `npm i --save-dev @types/node`
```

Той самий код на `main` компілювався чисто, лок-файли відрізнялися **лише** версією vitest.

**Перше (хибне) пояснення.** «Типи `node` приходять транзитивно через vitest 3, треба
оголосити `@types/node` явно». Це було зроблено (11.09–12.09), і це **не допомогло**: PR
усе одно падав.

**Справжня причина** — у `packages/shared/tsconfig.json` стоїть allowlist
`"types": ["@cloudflare/workers-types"]`. Директива `types` визначає, які **глобальні**
пакети типів потрапляють у програму. Пакет `@types/node` описує `node:*` через ambient
`declare module "node:fs"`, тож він працює, лише коли його **включено в програму**. Явна
залежність у `package.json` цього не робить: вона гарантує лише наявність файлів на диску.

Доказ (локально, `tsc --traceResolution`): із vitest 3 у програмі є
`@types/node/fs.d.ts` (6 згадок у трейсі) — бо його випадково підтягнула залежність; із
vitest 5 — **0 згадок**, і кожен `node:*` падає в «Skipping module … looks like an absolute
URI → not resolved». Тобто компіляція раніше трималася не на контракті, а на **випадковому
транзитивному типові**.

**Виправлення** — точкове, у самому файлі:

```ts
/// <reference types="node" />
```

Чому саме так, а не `"types": [..., "node"]` у `tsconfig` пакета: `packages/shared` — код
воркерів і браузера, і allowlist навмисно не пускає туди глобальні типи Node. Розширити
його означало б дозволити `process`, `Buffer`, `fs` у спільному коді **без помилки
компіляції**. Директива діє лише на один файл — тест, який справді читає `wrangler.toml` з
диска.

**Перевірено відтворенням, а не міркуванням.** Копія дерева PR-мерджу в ізольованій теці
всередині проєкту + `npm ci` + `tsc` відтворила помилку дослівно; у тій самій копії
директива її зняла (і варіант із `types: ["node"]` теж). Після перенесення на `main`:
`typecheck` — 6 воркспейсів чисто, тести 182/182, Prettier чисто.

**Урок, який варто пам'ятати:** тип, що приходить «у подарунок» від чужої залежності, — це
не контракт, а збіг. Мінімальне оновлення будь-якого пакета може його забрати.
