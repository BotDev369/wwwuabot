**3. Крок 3 «одного дизайну» (LOG §4.3).**
- **44 класи `wb-block-*` не мають жодного правила** — блоки стилізовані inline
  (`style={{ … }}`: 192 об'єкти, 30 хардкод-hex, 8 `rgba()`). Через це `data-brand`
  і `data-theme` до блоків **не доходять**, а `index.css` оболонок на них не впливає.
  **Дія:** порціями по 5–8 блоків переносити inline → `.wb-block-*` у `components.css`,
  починаючи з тих, де є хардкод-кольори.
- ~~**Дві реалізації тієї самої модалки дати**~~ — **закрито 12.09**: легасі-версію
  платформи видалено разом з островом `pages/mydate/`, лишилась `packages/ui` (193 рядки).
- **Мертвий CSS** — **почищено 12.09.2026 з обох боків**: 164 → 101 клас, якого немає в
  `src/` навіть як підрядок (каркас оболонок, `profile.css`, острів `mydate`-класів).
  Лишок — брендові легасі (`html[data-brand] .btn`, `.card`, `.kb-*`), яких немає в розмітці.
- ~~**Емодзі в UI**~~ — **закрито 12.09.2026**: 16 справжніх емодзі в 7 файлах замінено
  на `<Icon />`, і тепер новий емодзі не пройде CI (`check:quality`).
- **`↑ ↓ ✕` текстом** замість `<Icon />` у 5+ редакторах блоків адмінки — порушує власне
  правило дизайн-системи: символи не масштабуються з `size` і не читаються скрін-рідером.
  (Це **символи**, не емодзі, тому гейт їх не ловить — робота лишається ручною.)
- **`.usr-*` / `.scn-*` в адмінці дублюють `.wb-data-table` / `.wb-modal-*`** — найдорожчий
  пункт, робити тільки разом із візуальною перевіркою.

## 5. Чого цей план НЕ дасть (чесно)

| | |
|---|---|
| **Уже отримано** | CSS 7 366 → 6 330 (−1 036: спільні кирпичики каркаса + мертвий CSS обох оболонок), 686 → 48 рядків у `SiteEditorPage`, один діалог замість 33 зламаних викликів на iOS |
| **Що НЕ зміниться** | модель деплою, роутинг, бізнес-логіка, кількість воркерів, відсутність прода |
| **Чого не буде від рефакторингу** | тестів, моніторингу браузера, захисту адмінки Cloudflare Access — це окремі роботи, а не наслідок чистоти коду |

**Головний ефект — не рядки.** Зникає потреба правити одне й те саме у двох застосунках і
зникає клас багів «розсинхрон між оболонками» (приклади: `.block-card:hover` на мертвому
класі → кнопки блока були невидимі назавжди; нативний `prompt` → «Додати сторінку» на iOS
не робила нічого).

Оцінка «−70..75%» з `docs/PAGE_ENGINE_ARCHITECTURE.md` §6 стосується **окремих файлів**, а не
репозиторію: жоден рефакторинг не прибирає продукт (поточні числа — §0). Реалістично
скоротити можна кілька відсотків, і то переважно там, де є справжнє дублювання (`.usr-*` / `.scn-*`).
