# Рецепти: як робити те, що робиться часто

> Покрокові рецепти для типових задач. **Кожен закінчується тим, чим його перевірити** —
> рецепт без перевірки це побажання. Правила, на які рецепти спираються, — `AGENTS.md`;
> вигляд — `DESIGN_SYSTEM.md`.

## 0. Що чим перевіряється

| Питання | Гейт | Що саме ловить |
|---|---|---|
| Чи компілюється | `npm run typecheck` | типи у всіх 6 воркспейсах |
| Чи немає `any` і мертвого коду | `npm run lint` | ESLint, 0 попереджень |
| Чи клас має правило | `npm run check:css` | клас у розмітці без CSS; спільний код, стилізований лише в одній оболонці |
| Чи живий екран | `npm test` | регресії, зокрема тести, які читають CSS |
| Чи таблиця в реєстрі | `npm run check:db` | `CREATE TABLE` і ім'я таблиці поза `tables.ts` |
| Чи файл не «простиня» | `npm run check:quality` | >400 рядків, нативні діалоги, голий `100vh`, емодзі в UI |
| Чи документ не збрехав | `npm run check:docs` | бюджет розміру, мертві посилання й шляхи, свіжість `docs/API.md`, `AGENTS.md §N` |
| Чи ендпоїнти описані | `npm run doc:api` | перегенеровує `docs/API.md`; гейт падає, якщо файл розійшовся з кодом |

## 1. Новий ендпоїнт в `api-dev`

1. **Виберіть префікс — це вибір доступу.** Публічне (`/api/scenario/`, `/api/mydate/`, `/health`),
   користувач (`/api/my-dates`, `/api/notes`, `/api/contacts`, `/api/user/…`), адмін
   (`/api/admin/`, `/api/portal/`, `/api/bot/`). Адмінський шлях **поза** трьома адмін-префіксами
   проходить повз єдиний гейт і стає публічним мовчки.
2. Рядок у `api-dev/src/router.ts`: `if (pathname === "…" && request.method === "…")` →
   `return handleX(request, env)`.
3. Контролер у `api-dev/src/controllers/` — новий файл або наявний домен. Ідентичність —
   **тільки** `resolveUserId()` (обов'язкова) або `tryResolveUserId()` (публічний) з
   `api-dev/src/shared/identity.ts`.
4. Коди відповідей: зайняте — `409`, невалідне — `400`, «немає» і «чужий» — **однаково** `404`
   (сам код відповіді теж підказка). Право власника перевіряється **до** підказок про існування
   об'єкта.
5. `npm run doc:api` — інвентар оновлюється сам.
6. Тест контролера поруч (`*.controller.test.ts`) + тест на префікс у `api-dev/src/router.test.ts`,
   якщо додали групу доступу.

**Перевірка:** `npm run check:docs` (інвентар свіжий), `npm test`, `npm run typecheck`.

## 2. Нова колонка (або таблиця) D1

1. Рядок у реєстрі `packages/shared/src/database/tables.ts`: `name`, `owner`, `purpose`, `create`
   (у `create` — нова колонка), за потреби `indexes`.
2. `ensureTables(db, ["ім'я"])` у воркері-власнику — там, де таблиця потрібна вперше.
3. Рядок у `docs/DATA_MODEL.md` (хто власник, хто пише, що це).

**Перевірка:** `npm run check:db`. Колонку, яку пише код, але якої немає в реєстрі, гейт не
пробачить.

## 3. Перебудова таблиці (PK, `UNIQUE`, тип)

`ensureTables` **тільки додає** колонки, тому це окремий усвідомлений крок: два SQL у
`scripts/migrations/` — копія (`*-01-copy.sql`, лише `INSERT`) і заміна (`*-02-swap.sql`, стара
таблиця лишається як `*_legacy_<дата>`). Деталі — `docs/DATA_MODEL.md`.

**Перевірка:** `npm run check:db` після деплою воркера + `SELECT COUNT(*)` до і після (перенос, який
щось пропустив, мусить назвати це у звіті).

## 4. Новий кирпичик UI (клас)

1. **Спочатку правило** в `packages/shared/src/styles/` (`components.css`, `app-chrome.css` або CSS
   теми), тоді вжиток у розмітці — не навпаки.
2. Якщо клас рендерить спільний код (`packages/ui`), правило має жити в shared: у `index.css`
   однієї оболонки друга його не побачить.
3. Деталь, однакова в обох оболонках, — це **кирпичик**, а не «стиль оболонки». Брендові теми
   (`apple.css` / `android.css`) стилізують кирпичик, а не приватний клас оболонки.

**Перевірка:** `npm run check:css`; борг у `scripts/css-baseline.mjs` тільки зменшується.

## 5. Новий екран платформи (TWA)

1. Маршрут у `web-platform-dev/src/app/router.tsx`; авторизація — `app/AuthGate.tsx`.
2. Сторінка в `web-platform-dev/src/pages/` + хук `use<Екран>.ts` (стан і бізнес-логіка — у хуку,
   сторінка лише рендерить).
3. Дані — через `apiFetch` (`web-platform-dev/src/shared/api/client.ts`) у `api-dev`. Прямого
   доступу до D1 платформа не має.
4. Розмітка — з кирпичиків (`.wb-*`), іконки — `<Icon />`, діалоги — `useDialog()`.

**Перевірка:** `npm test` (чиста логіка хука), `npm run check:css`, візуально на 360px.

## 6. Новий екран або кнопка бота

1. **Контент — це дані, а не код:** рядок у `scenarios` (`slug`, підпис, кнопки) через адмінку.
   Нова сторінка вебу — вкладка «Сторінка», подання в боті — вкладка «Бот».
2. `callback_data` кнопки — це `slug` рядка. Кнопка `web_app` веде на **ту саму** сторінку
   (`WEB_PLATFORM_URL` + `toWebPath`).
3. Код бота змінюють лише тоді, коли потрібен **новий потік** (нове джерело апдейтів, новий спосіб
   переходу) — `bot-dev/src/core/router/bot-router.ts`; система описана в `bot-dev/README.md`.
4. Персональний лінк контакту — виняток із правила «payload = адреса»: код перевіряється першим
   (`bot-dev/src/modules/contacts/contact-link.ts`).

**Перевірка:** перехід у боті вручну; `npm run doc:api` не потрібен (ендпоїнти не змінились).

## 7. Спільний код (коли в 2+ місцях)

Правило «двічі — в спільне»: логіка й типи — у `packages/shared/`, React-компоненти — у
`packages/ui/`, новий підшлях у `exports` пакета. Серверну логіку воркера (роутинг, мідлвари) і
`wrangler.toml` у shared **не** виносять.

**Перевірка:** `npm run typecheck` (спільний код компілюється в усіх, хто його імпортує).

## 8. Тест

Vitest, файл `*.test.ts(x)` поряд із модулем. Обов'язково — для **чистої логіки** (правила вигляду,
адреси, підрахунки, фільтри) і для того, що гейт не бачить. Правило, яке вже перевіряє тест, у
документі не дублюється — у документі лишається посилання на тест.

**Перевірка:** `npm test` (червоний тест блокує деплой так само, як червоний гейт).

## 9. SQL на дев-базі

Запит виконують **із кореня** репозиторію (`wrangler` шукає `.env` у теці запуску) —
див. `docs/DATA_MODEL.md`. Міграції з черги CI запускає людина через
`.github/workflows/d1.yml`.

| Що з'явилось | Куди |

| Новий рецепт | цей файл |
| Новий гейт або поріг | `docs/QUALITY_GATE.md` |
| Новий ендпоїнт | нікуди вручну — `npm run doc:api` |
| Нова таблиця або колонка | реєстр `tables.ts` + рядок у `docs/DATA_MODEL.md` |
| Новий токен, правило вигляду | `docs/DESIGN_SYSTEM.md` (номер правила не змінювати) |
| Виміряне число | **нікуди**: його друкують гейти |
